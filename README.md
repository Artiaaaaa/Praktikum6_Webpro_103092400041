1.	Jelaskan secara singkat apa itu JavaScript dan kegunaannya! [5 Poin]
Jawab:
JavaScript adalah bahasa pemrograman tingkat tinggi yang digunakan terutama untuk mengembangkan antarmuka web yang interaktif. Diperkenalkan pertama kali oleh Netscape pada tahun 1995, JavaScript menjadi bagian penting dari teknologi web bersama HTML dan CSS. Kegunaannya antara lain mengatur elemen HTML/CSS, validasi form, menangani event (klik, input), dan mengambil data dari server tanpa reload halaman.

2.	Jelaskan secara singkat apa itu jQuery dan kegunaannya! [5 Poin]
Jawab:
Jquery adalah library JavaScript yang menyederhanakan penulisan kode. Kegunaannya untuk memilih elemen, manipulasi DOM, penanganan event, membuat animasi, dan AJAX dengan sintaks yang lebih singkat dan mudah dibaca sehingga mempercepat proses pengembangan web.

3.	Jelaskan perbedaan JavaScript dan jQuery! [10 Poin]
Jawab:
- JavaScript adalah bahasa pemrograman, sedangkan jQuery adalah library yang dibangun di atas JavaScript.
- jQuery harus diimpor lewat CDN atau file lokal, sedangkan JavaScript sudah bawaan browser.
- Sintaks jQuery lebih ringkas, misalnya $("#id").hide() dibanding document.getElementById("id").style.display = "none".
- JavaScript murni lebih ringan dan fleksibel, sedangkan jQuery menambah ukuran file dan bergantung pada library tersebut.
